MAHALAKSHMI GARMENTS WEBSITE — HOW TO PUT IT LIVE
====================================================

WHAT'S IN THIS FOLDER
- index.html            the website
- images/               all photos
- favicon + og-image    icons and the preview image shown when the link is shared
- robots.txt, sitemap.xml, 404.html   standard website files

STEP 1 — PUT IT ONLINE (about 1 minute, free)
1. On a computer, go to  app.netlify.com/drop
2. Sign up free if asked (use the factory email).
3. Drag THIS WHOLE FOLDER onto the page.
4. Done — Netlify gives you a temporary link like something.netlify.app. The site is live.

STEP 2 — CONNECT THE REAL DOMAIN (mahalakshmi.co.ke)
1. In Netlify: Site settings -> Domain management -> Add a domain -> type mahalakshmi.co.ke
2. Netlify shows you 4 "nameservers". Log in to wherever mahalakshmi.co.ke was bought
   (the registrar) and replace the existing nameservers with Netlify's 4.
3. Wait a few hours. Netlify adds the padlock (HTTPS) automatically.

STEP 3 — SWITCH ON THE ENQUIRY FORM (one time, 1 minute)
The quote form sends enquiries to heman.boodia@mahalakshmi.co.ke through a free
service called FormSubmit. The FIRST time anyone presses "Send enquiry" on the live
site, FormSubmit emails heman.boodia@mahalakshmi.co.ke a confirmation.
OPEN THAT EMAIL AND CLICK "ACTIVATE". After that, every enquiry arrives as a
normal email. Tip: submit a test enquiry yourself right after the site goes live,
then activate from the inbox.

UPDATING THE SITE LATER
Drag the updated folder onto Netlify again — it replaces the old version.
